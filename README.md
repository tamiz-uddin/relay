# Relay — desktop installers

Public home of the Relay desktop builds. The application source lives in a
private repository; this one only carries release artifacts so the download
page can resolve them without authentication.

| Platform | Formats |
|---|---|
| Linux | `.deb` (Debian/Ubuntu), `.rpm` (Fedora/RHEL), `.AppImage` (portable) |
| Windows | NSIS `.exe` installer (x64) |
| macOS | `.dmg` (Apple Silicon + Intel) — built on a macOS host |

Get the newest build from [Releases](https://github.com/tamiz-uddin/relay/releases/latest),
or from [relay.tamiz.pro/downloads](https://relay.tamiz.pro/downloads).

Builds are unsigned: Windows SmartScreen and macOS Gatekeeper will warn on the
first launch.

Cloud: [relay.tamiz.pro](https://relay.tamiz.pro)
